# 0004. 지배 코어 전체를 다른 프로그램에서 비우고, 권한 없는 프로그램은 건너뛴다

- 날짜: 2026-11
- 결정: 지영

## 문제

V2는 게임이 쓰는 논리 CPU만 다른 프로그램에서 비웠습니다. 그러면 밀려난 프로그램이 같은 물리 코어의 다른 논리 CPU(SMT 형제)로 몰려서, 지배 스레드와 코어 자원을 나눠 쓰게 됩니다.

## 선택지

| | 다른 프로그램을 빼는 범위 | 남는 문제 |
|---|---|---|
| A | V2처럼 게임 논리 CPU만 | 지배 코어의 형제 논리 CPU에 다른 프로그램이 몰림 |
| B (선택) | 지배 물리 코어의 모든 논리 CPU + 보조 논리 CPU | 다른 프로그램이 쓸 CPU가 줄어듦 |

권한 없는 프로그램(보호 프로세스, Windows 중요 프로세스)은 강제로 바꾸려 하거나 실패로 처리하는 대신 건너뜁니다.

## 결정

B. 당시 결정: "지배 코어는 지금 실행 중인 다른 프로세스의 선호에서 빼는 걸로 하고, 권한이 없는 프로그램은 넘겨."

## 이유

> ✏️ **직접 작성:** 왜 물리 코어 전체를 비워야 했는지, 왜 권한 없는 프로그램은 실패 대신 건너뛰기로 했는지 적어 주세요.

## 결과

- 2026-11-18 실측 17회에서 지배 논리 CPU에 남은 다른 부하는 0~1.5%였습니다.
- 한계: 물리 코어가 2개인 PC에서는 다른 프로그램이 쓸 논리 CPU가 1개만 남습니다. Pentium G4560 21회 실행 중 1회는 그 논리 CPU가 포화돼 지배 코어까지 부하가 넘쳤습니다(지배 스레드 91.3%).
- 건너뛴 프로그램은 개수와 예시 3개를 화면에 알려 줍니다.
