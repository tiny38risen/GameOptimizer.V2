# 0005. 배포는 압축만 풀면 되게 하고, 관리자 권한은 항상 요청한다

- 날짜: 2026-11-16
- 결정: 지영

## 문제

주 사용자는 30대 이상이고, 귀찮거나 복잡하면 쓰지 않는 사람들입니다. 설치 과정이 하나라도 더 있거나, 어떤 파일을 실행해야 할지 헷갈리면 거기서 그만둡니다.

## 선택지

| 항목 | 고른 것 | 고르지 않은 것 |
|---|---|---|
| .NET 런타임 | 프로그램에 포함 (자체 포함 배포) | 사용자가 따로 설치 |
| 폴더 구성 | 최상단에는 `GameOptimizer.exe` 하나, 나머지는 `app\` 폴더 | 파일 수백 개를 한 폴더에 |
| 관리자 권한 | 런처가 항상 요청 | 필요할 때만 요청 |

## 결정

위 표의 "고른 것"입니다.

## 이유

> ✏️ **직접 작성:** 사용자층 외에 덧붙일 이유가 있으면 적어 주세요. 특히 관리자 권한을 "필요할 때만"이 아니라 "항상" 요청하기로 한 이유를 적어 주세요. (참고: 관리자 권한으로 실행된 게임은 관리자 권한이 있어야 설정을 바꿀 수 있습니다.)

## 결과

- 3.0.0-beta1 배포 파일은 압축을 풀고 `GameOptimizer.exe`만 실행하면 됩니다.
- 대가: 런타임을 포함해서 zip이 약 60MB이고, 실행할 때마다 Windows 권한 확인 창이 뜹니다.
