# 0005. 배포는 압축만 풀면 되게 하고, 관리자 권한은 항상 요청한다

- 날짜: 2026-11-16
- 결정: 지영

## 문제

주 사용자는 30대 이상이고, 귀찮거나 복잡하면 쓰지 않는 사람들입니다. 설치 과정이 하나라도 더 있거나, 어떤 파일을 실행해야 할지 헷갈리면 거기서 그만둡니다.

## 선택지

| 항목 | 고른 것 | 고르지 않은 것 |
|---|---|---|
| .NET 런타임 | 프로그램에 포함 (자체 포함 배포) | 사용자가 따로 설치 |
| 폴더 구성 | 최상단에는 `GameOptimizer.exe` 하나, 나머지는 `app\` 폴더 | 파일 수백 개를 한 폴더에 |
| 관리자 권한 | 런처가 항상 요청 | 필요할 때만 요청 |

## 결정

위 표의 "고른 것"입니다.

## 이유

모든 선택의 기준은 "사용자가 할 일을 하나라도 줄인다"입니다.

- **런타임 포함:** 배포 용량을 줄이려고 런타임을 따로 설치하게 하는 방안도 나왔지만, 그러면 사용자가 귀찮아져서 쓰지 않습니다. 용량보다 단순함을 택했습니다.
- **최상단 exe 하나:** 자체 포함 배포는 파일이 수백 개라, 그중에서 실행 파일을 찾는 것부터가 걸림돌입니다. 최상단에는 실행할 파일 하나만 두고 나머지는 `app\` 폴더로 넣었습니다.
- **관리자 권한 항상 요청:** 특정 게임(`Client.exe`)이 관리자 권한인지 확인해서 그때만 요청하는 방안도 있었지만, 특정 게임에 맞추지 않기로 했습니다. 관리자 권한으로 실행된 게임은 관리자 권한이 있어야 설정을 바꿀 수 있고, 사용자가 권한 개념을 몰라도 "왜 안 되지?" 하는 상황이 생기지 않게 하려면 항상 요청하는 쪽이 단순합니다. 사용자는 권한 확인 창에서 "예"만 누르면 됩니다.

## 결과

- 3.0.0-beta1 배포 파일은 압축을 풀고 `GameOptimizer.exe`만 실행하면 됩니다.
- 대가: 런타임을 포함해서 zip이 약 60MB이고, 실행할 때마다 Windows 권한 확인 창이 뜹니다.
